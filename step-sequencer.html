📖 使用说明 · 完整操作指南（点按展开 / 收起）
🎹 和弦进行轨（顶部墨色卡）：全曲和声的唯一来源，每个方块是一个和弦段，方块宽度＝它持续的拍数。点方块挑级数（并试听）、‹ › 改拍长、⧉ 从中间拆开插入一个新和弦、✕ 删除；🎲 随机同风格 / ⤵ 从旋律推导 一键换整条。🔊 和弦声：播放时和弦轨每拍触发一次当前和弦，音色可在右侧下拉里换（默认跟风格），不想让它响就点成「关」。改动过之后，切风格不会再覆盖和弦进行。方块下方还有「常用和弦进行」下拉：列出当前风格与当前调式的常用走向（如 I – V – VI – IV），选一条即整条替换、拍数自动铺满，右侧回显当前走向；手动改过则显示「自定义」。
小节数：每张卡片参数行最前面是 小节 1 / 2 / 3 / 4 / 8——每个声部各自独立，可以不一样长；播放时各声部按自己的长度循环。加长会把第 1 小节的内容平铺到后面（改起来更快），缩短则保留前面。和弦进行轨也有自己的「小节」（和弦卡头部），与声部小节数无关：声部 1 小节时和弦轨照样可以是 2 小节 4 个和弦，播放时各自按长度循环，和弦比声部短就自动循环铺满。
速度（每步时值）：每张卡片参数行的 速度 1/16 · 1/8 · 1/4——默认 1/16（每格一个十六分音符，与全曲同速）；选 1/8 该声部慢一倍（16 步走 2 小节）、1/4 慢三倍（16 步走 4 小节）。只改变这一个声部的播放速率与发音长度，音序内容与小节数都不变，播放头也跟着变慢，导出的 MIDI 同步反映。混速时全曲循环长度取最慢的那个声部。
🔗 跟随和弦（开关）：每个旋律声部参数行「和声」组里的开关按键——打开后，你在音序网格上摆的 step 位置完全不动，只有实际播放出来的音高被实时折算到当前和弦内（最接近的和弦音）。此后每次改和弦（挑级数、拆段、删段、换常用走向、🎲 随机、⤵ 从旋律推导）都会立刻反映到听感上。关掉开关，音高立即完整恢复成你摆下的原样——因为音序本身从未被改写。
网格上被折算的音会在实际发声的那一行画一枚虚框淡标记，鼠标悬停格子标题会提示「🔗 跟随和弦 → 实际发 X」。播放、试听、MIDI 导出三者一致都使用折算后的音高。开关状态随存档保留。✨ 和声重排与 🎼 编配始终使用和弦进行轨的和声。
🎼 琶音模式（ARP，开关 + 图案 + 节奏 + 八度 + 音长）：「和声」组里「跟随和弦」旁边的「琶音」开关 + 图案下拉 + 节奏下拉 + 八度下拉 + 音长下拉——开启后，实际音高在播放时从当前和弦的和弦音音池（音高从低到高：根音 · 三音 · 五音 · 高八度根音；七和弦自动多一个七音）按图案生成：上行 顺着爬 / 下行 倒着走 / 上下 到顶折返（端点不重复）/ 随机（同一格每轮循环同音，网格预览即实际）。音高始终实时取自上方和弦进行轨——改和弦、换进行、调拍长，琶音即时跟着换（琶音开启时由琶音接管发声，「跟随和弦」开关的折算暂不参与）。
节奏下拉控制播放速度（以该声部「速度」档的格子为基准）：跟画＝只在你画的 step 上发声（空步不响，画的音符当节奏栅格用）；1/16 · 1/8 · 1/4＝按节拍自动滚——每 1 / 2 / 4 格响一个琶音音，画没画的格子也按拍触发，画下的音符让位变暗但原样保留（切回跟画即复原）。
八度下拉（Octaves 1–4）：音池向上叠加 1–3 组高八度同音级行，琶音跨多个八度 sweeping——经典合成器琶音的标志性格局，只在本组八度里 4 个音来回打转就是「缺了 ARP 味」的最常见原因。
音长下拉（Gate 25%–100%）：每个音持续「一步 × Gate%」——25% 短促打击感（staccato）、50% 适中、75% 饱满、100% 连满无缝（legato）。与「跟随和弦」一样非破坏性：音序从未被改写，关掉立即恢复原样；播放 / 试听 / MIDI 导出三者一致，网格上还会用虚框淡标记画出每步实际发出的音。开关、图案、节奏、八度与音长随存档保留，示例曲的「琶音 Arp」声部默认开启（1/16 自动滚）。
🎚 效果器：旋律声部卡片参数行末尾有「延时 Delay」下拉 + Mix 强度滑杆——拍打回声 Slapback / 1/8 短延 8th / 附点 1/8 Dotted 8th / 1/4 回声 1/4 Note / 磁带回声 Tape Echo（带磁带抖动音高颤动）/ Dub 回声 Dub（长尾高反馈）/ 模拟回声 Analog（柔和暗色重复），回声时间随 BPM 自动同步。鼓声部不做延时（给鼓点加回声容易糊），它只有音量。和弦进行轨也有延时：墨色卡右侧「延时 Delay」下拉，紧跟就是它的 Mix 强度滑杆，只作用于和弦声（试听即刻听得到），与声部延时互不干扰。顶栏「混响 Reverb」下拉 + Mix（湿度）滑杆作用于总输出——房间 Room / 混响室 Chamber / 板式 Plate / 音乐厅 Hall / 教堂 Cathedral / 氛围空间 Ambient / 弹簧混响 Spring（吉他放大器味）/ 门限混响 Gate（80 年代鼓组急截断），带预延迟、高频阻尼与早期反射的空间仿真。全部设置都会存档。
🎛 调音台 Mixer（页面最底部）：每个声部一条通道条，上行是色标 · 编号 · 声部名 + 音色、延时开关 + 效果下拉 + Mix 强度；下行是M 静音 / S 独奏、音量推子、声像 L / C / R。延时开关默认关——想给某个声部加回声才勾上，右边的下拉选预设、下面的滑杆调回声比例（勾上时默认给 1/4 回声）。最后一条是和弦进行轨的总线（它有音量、静音与延时，没有独奏与声像）。宽屏一行两个声部，窄屏自动变成一行一个。拖动推子即时生效，播放中也可调；M 静音 / S 独奏在播放中点下也立刻见效（连延时的残留回声一起断掉）。调音台与声部卡里的是同一份状态——在哪边改都会一起变、一起存档。鼓声部不做延时，所以显示「— 无延时」，它还支持在鼓格上直接滚动滚轮调音量（Shift + 滚动才是调那一击的力度）。
🎿 力度 Velocity：在旋律声部已点亮的格子上滚动滚轮调该步力度（上滚增强 / 下滚减弱，20%–100%），格子颜色会随力度变淡变实，试听即时反映；触摸屏长按格子也可呼出力度 / 清除小面板。播放与 MIDI 导出都带真实力度——轻拍副歌、重拍 drop 一目了然。没调过的步用默认人性化力度（±随机微差）。
↶ 撤销 Undo：Ctrl+Z 或顶栏「↶ 撤销」按钮，可回退最近 60 步操作——覆盖手摆音符、调力度、🎲 / ✨ / 🎼 生成、和弦轨编辑、切风格、清空、增删排序声部等。空格 播放 / 停止。
音乐风格：工具行「风格」黑色胶囊（手机端点 ⚙ 展开设置面板）。切换风格会同步 BPM / 摇摆、按风格重写鼓声部与和弦进行，✨ 与 🎼 也照它生成（氛围稀疏长音、电子密而跳、爵士七和弦与摇摆…）。
步进音序网格：每个旋律声部的音序是一张步进网格——纵向 8 行＝8 个音级（最上面最高音，行首标注音名如 C5 / B4 / A4），横向每一列＝一拍里的一个十六分步，与上方步号一一对齐。点一下空格子＝放置音符并即时试听；点一下已点亮的格子＝清除；按住拖过一排格子＝连续涂抹（首格决定是放还是删）；Enter / 空格 切换、Delete 清除。手摆的音（✨ 优化的锚点来源）会带一圈白色描边，一眼区分「我摆的」和「生成的」。窄屏自动把一小节拆成 8 步或 4 步一行，不需要横向滚动。
展开 / 收起音序：每张声部卡都可折叠——点卡片左侧的 ▸ 三角、点头部任意空白处或点摘要行即可展开 / 收起。同一时刻只展开一个声部（手风琴式），收起时头部下方留一行摘要（小节数 · 速度 · 音色 · 音符数 / 跟随和弦），不看面板也能掌握状态。收起不会影响播放与音序内容。
排序与鼓：卡片右上角 ↑ ↓ 换位。鼓：网格按小节分组直接点击，★ 是风格推荐预设，🎲 按风格生成律动；鼓没有延时（在调音台那条通道上调音量，或在鼓格上滚动滚轮）。空格 播放 / 停止。
✨ 和声重排（Harmonize）：以你手动摆的音为基准（强拍锚点始终保留；✨ / 🎼 生成的音不算锚点），在风格与和声约束下用动态规划求整句最优线，密度按小节数同比放大。连点每次都不同：弱拍倾向每轮随机衰减，并在多个达标方案里加权抽取；想固定一处就亲手拧一下那格。🎲 随机生成（旋律卡上）：无视现有内容、按当前风格从零造一条全新旋律（连点每次不同，旧的手动锚点会被作废），适合推倒重来。🎼 一键编配：按和弦进行轨补齐贝斯 / 琶音 / 铺底 / 鼓组（长度自动铺满全曲），每次点击结果都不同。
