🎹 和弦进行轨（顶部墨色卡）：全曲和声的唯一来源，每个方块是一个和弦段，方块宽度＝它持续的拍数。点方块挑级数（并试听）、‹ › 改拍长、⧉ 从中间拆开插入一个新和弦、✕ 删除；🎲 随机同风格 / ⤵ 从旋律推导 一键换整条。🔊 和弦声：播放时和弦轨每拍触发一次当前和弦，音色可在右侧下拉里换（默认跟风格），不想让它响就点成「关」。改动过之后，切风格不会再覆盖和弦进行。
小节数：每张卡片参数行最前面是 小节 1 / 2 / 3 / 4 / 8——每个声部各自独立，可以不一样长；播放时各声部按自己的长度循环。加长会把第 1 小节的内容平铺到后面（改起来更快），缩短则保留前面。和弦进行轨也有自己的「小节」（和弦卡头部），与声部小节数无关：声部 1 小节时和弦轨照样可以是 2 小节 4 个和弦，播放时各自按长度循环，和弦比声部短就自动循环铺满。
⟳ 对齐和弦：每个旋律声部卡片上的一次性触发按钮——点一下，把该声部现有音符吸附到最近的和弦音（和弦外的音就近挪进和弦内）。调整和弦轨不会自动挪动声部；和弦轨改完后再点一次即可重新对齐。✨ 优化与 🎼 编配始终使用和弦进行轨的和声。
🎚 效果器：每张声部卡（含鼓）参数行末尾有「延时」下拉 + 「强度」滑杆——拍打回声 / 1/8 短延 / 附点 1/8 / 1/4 长回声 / 空间漂移，回声时间随 BPM 自动同步，强度控制效果量。顶栏「音量」旁有「混响」下拉 + 强度滑杆（作用于总输出，所有声部与和弦声都过它）——房间 / 板式 / 音乐厅 / 教堂 / 氛围空间，衰减与湿度逐级加大。全部设置都会存档。
音乐风格：工具行最左侧黑色胶囊。切换风格会同步 BPM / 摇摆、按风格重写鼓声部与和弦进行，✨ 与 🎼 也照它生成（氛围稀疏长音、电子密而跳、爵士七和弦与摇摆…）。
旋钮步进：点击＝顺时针一档（低→高，再回到「关」）；拖拽＝连续旋转；Shift+点击 / 右键＝逆时针；中键＝开 / 关；空格 播放 / 停止。排序：卡片右上角 ↑ ↓ 换位。鼓：网格按小节分组直接点击，★ 是风格推荐预设，🎲 按风格生成律动。
✨ 每声部独立优化：以你手动摆的音为基准（强拍锚点始终保留；✨ / 🎼 生成的音不算锚点），在风格与和声约束下用动态规划求整句最优线，密度按小节数同比放大。连点每次都不同：弱拍倾向每轮随机衰减，并在多个达标方案里加权抽取；想固定一处就亲手拧一下那格。🎲 随机生成（旋律卡上）：无视现有内容、按当前风格从零造一条全新旋律（连点每次不同，旧的手动锚点会被作废），适合推倒重来。🎼 一键编配：按和弦进行轨补齐贝斯 / 和弦音型 / 铺底 / 鼓组（长度自动铺满全曲），每次点击结果都不同。
